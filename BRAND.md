# Cartwheel — краткий бренд-гайд

Справочник для переноса страниц из Claude Design в этот репозиторий. Источник — дизайн-система
проекта (https://claude.ai/artifact/LpuhBnsZFh9eFtX7PBktMu) плюс реальный извлечённый исходник сайта.

**Важно:** точные значения токенов (цвета, радиусы, тени) уже заданы в [`css/styles.css`](css/styles.css)
`:root` — они проверены напрямую по реальному исходнику Claude Design и являются источником истины.
В самой дизайн-системе `tokens.json`/`tokens.css` — это реконструкция «по памяти» (например,
`--teal-d` там `#008870`, а в нашем реальном исходнике `#007A64`), поэтому **не копировать** оттуда
значения токенов — только использовать как справочник по смыслу/структуре.

## Голос и тон
- Уверенный, «оператор — оператору»: обращение на «вы/ваш» (fleet, data, customer).
- Конкретные цифры вместо прилагательных: «под 1 секунду», «$430 против $40», «97% вовремя», «50+ провайдеров».
- Sentence case в заголовках; UPPERCASE только для eyebrow-кикеров.
- Короткие, хлёсткие заголовки секций, часто с точкой в конце.
- Без эмодзи — никогда.
- CTA: «Book a demo», «See how it works», «Talk to sales».

## Визуальные принципы
- Цвета: teal `#00997D` (бренд/кнопки/иконки), teal-d (hover), slate (текст/тёмные секции),
  accent-мятный (акценты/статистика). Не больше 1–2 фоновых цветов на экран.
- Шрифты: Ubuntu — заголовки и eyebrow; Inter — текст и UI.
- Радиусы: карточки 16px, кнопки 10px, мелкие элементы 8px, чипы — пилюля (999px).
- Бордеры: тонкие 1px хairline ~12% непрозрачности; на hover — teal.
- Тени: мягкие, двухслойные; у карточек на hover — teal-тонированная.
- Фоны — сплошные цвета/мягкие градиентные «подложки» секций, без фото-полотен позади текста,
  без паттернов/шумов/радиальных glow.
- Иконки — только Tabler Icons (`<i class="ti ti-...">`), без эмодзи и самодельных SVG.

## Компоненты сайта
Переиспользуемые паттерны уже в `css/styles.css`/`js/main.js`: `.feat-card`, `.btn-solid`/`.btn-outline`/
`.btn-gradient`, `.eyebrow`, `.cat-tcard`-карусель отзывов, `.cat-faq-item`, логотип-марки `.logo-marquee`,
`.cat-check-list`, `.cat-stats`. Шапка/подвал — общие на всех страницах.

## Ассеты из дизайн-системы, добавленные в этот репозиторий
- `assets/ai-*.svg` — значки ассистентов (ChatGPT, Claude, Google, Grok, Perplexity) для блока
  «спроси ассистента».
- `assets/cust-*` — дополнительные логотипы брендов-клиентов (JackRabbit, Wings Over, Tacos4Life,
  RMDA, Fulflld, Omnicart, Catalogue, Standing's, Calif Chicken, Flyboy, Illegal Pete's, Mandy's,
  Mr Jim's + белые варианты Portillo's/Potbelly/P.F. Chang's/Jason's Deli для тёмных секций).
- `assets/int-*` — дополнительные логотипы интеграций/доставки (Burq, ChowNow, delivery.com,
  ezCater (white), GoParrot, Hana, KitchenHub, Nash, Omnicart, Orders.co, Square, Thanx, Treez,
  UberEats, Zuppler).
- `assets/people/*.jpg|png` — фото людей для карточек отзывов (barnett, northway, osanloo, polk,
  scarpino, schuster).

Эти файлы реальные (загружены как есть), но пока не использованы ни на одной странице — подключать
по мере переноса страниц, где они реально нужны (кейсы, интеграции, отзывы).
